# Getting started

This walks through a new service built on common-go. The [examples](../../examples/) module is the finished version of the same steps (a user service with CRUD, paging, streaming and validation), so copy from it when you start a real project.

## 1. Layout

```
myservice/
  go.mod                 # go 1.27
  buf.yaml  buf.gen.yaml
  proto/myservice/v1/*.proto
  gen/go/...             # generated, committed
  internal/...           # service implementation
  cmd/server/main.go
  configs/config.yaml
```

## 2. Define the API in proto

```protobuf
syntax = "proto3";
package myservice.v1;

import "buf/validate/validate.proto";
import "google/api/annotations.proto";

service GreeterService {
  rpc SayHello(SayHelloRequest) returns (SayHelloResponse) {
    option (google.api.http) = {get: "/v1/hello/{name}"};
    option idempotency_level = NO_SIDE_EFFECTS; // also allows Connect GET
  }
}

message SayHelloRequest {
  string name = 1 [(buf.validate.field).string = {min_len: 1, max_len: 50}];
}

message SayHelloResponse {
  string message = 1;
}
```

- `google.api.http` annotations define the REST routes (grpc-gateway).
- `buf.validate` rules are enforced by the server on every protocol (protovalidate). Code generated by the older protoc-gen-validate (`Validate()` methods) is also enforced.
- `idempotency_level = NO_SIDE_EFFECTS` lets Connect clients call the method with HTTP GET.

## 3. Generate code

`buf.yaml`:

```yaml
version: v2
modules:
  - path: proto
deps:
  - buf.build/bufbuild/protovalidate
  - buf.build/googleapis/googleapis
lint:
  use: [STANDARD]
breaking:
  use: [FILE]
```

`buf.gen.yaml`:

```yaml
version: v2
managed:
  enabled: true
  override:
    - file_option: go_package_prefix
      value: example.com/myservice/gen/go
  disable:
    - module: buf.build/googleapis/googleapis
    - module: buf.build/bufbuild/protovalidate
plugins:
  - remote: buf.build/protocolbuffers/go
    out: gen/go
    opt: paths=source_relative
  - remote: buf.build/grpc/go
    out: gen/go
    opt: paths=source_relative
  - remote: buf.build/grpc-ecosystem/gateway
    out: gen/go
    opt: paths=source_relative
```

```bash
go install github.com/bufbuild/buf/cmd/buf@latest
buf dep update && buf lint && buf generate
```

Add `buf.build/connectrpc/go` only if you need streaming over Connect (see [connectrpc.md](connectrpc.md)); unary Connect works without it.

## 4. Implement and serve

```go
func main() {
	var cfg Config
	if err := config.Init(context.Background(), "", &cfg, dependencies.WithNewFns(database.New)); err != nil {
		log.Action("InitConfig").Fatal(err.Error())
	}
	gs := grpcmux.NewServer(grpcmux.WithConfig(&cfg.Apis))
	impl := &greeter{deps: &cfg.Dependencies}
	grpcmux.RegisterConnectService(gs, &pb.GreeterService_ServiceDesc, impl) // gRPC + Connect
	_ = pb.RegisterGreeterServiceHandlerServer(context.Background(), gs.ServeMux(), impl) // REST
	gs.Start()
}
```

See [configuration.md](configuration.md) for `Config` and [dependencies.md](dependencies.md) for the dependency struct.

## 5. Run and call it

```bash
go run ./cmd/server            # reads configs/config.yaml (or $CONFIG_PATH, or -c path)
curl localhost:8080/v1/hello/Ada
curl -X POST localhost:8080/myservice.v1.GreeterService/SayHello -H 'Content-Type: application/json' -d '{"name":"Ada"}'
curl 'localhost:8080/myservice.v1.GreeterService/SayHello?encoding=json&message=%7B%22name%22%3A%22Ada%22%7D'  # Connect GET
grpcurl -plaintext -d '{"name":"Ada"}' localhost:8081 myservice.v1.GreeterService/SayHello
curl localhost:8080/healthz ; curl localhost:8080/readyz ; curl localhost:9090/metrics
```
